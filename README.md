# Book Writing Studio

A bilingual (Arabic/English) professional book authoring, manuscript editing, and AI co-authoring studio. Designed for writers, historians, novelists, and researchers to draft, organize, and polish manuscripts with precision.

## Key Features

- **Bilingual Manuscript Editor**: Full support for Arabic (RTL) and English (LTR) with custom typography, font choices (Amiri, Tajawal, Cairo, Inter, Merriweather, etc.), adjustable font sizes, and layout width customization (Page, Wide, and Full-Width Google Docs styles).
- **Dual AI Assistants**:
  - **AI Assistant Drawer**: Conversational consultant for brainstorming, chapter structuring, and deep contextual refinement.
  - **"Talk & Write" AI Scribe**: Speech-to-prose studio that transforms spoken thoughts and reflections into eloquent first-person book prose, plus Biographer Interview Mode.
- **Organization & Structure**: Multi-volume, multi-chapter management with corkboard outline views, scene notes, scratchpads, and progress tracking.
- **Local & Cloud Persistence**: Automatic local storage with Google Drive synchronization and export capabilities (PDF, Markdown, HTML, JSON).
- **Eye-Comfort Themes**: Carefully tuned color palettes and anti-glare text selection highlights designed for marathon writing sessions.

## Tech Stack

- React 18 + Vite + TypeScript
- Tailwind CSS
- Lucide Icons
- Google Gemini API (Server-side proxy)
